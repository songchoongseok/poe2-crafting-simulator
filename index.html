① 시작 아이템 설정

게임 한국어 데이터로 아이템명을 표시합니다. 확인되지 않은 이름은 원문 그대로 유지합니다.

베이스의 장착 요구 레벨과 실제 드롭 아이템 레벨은 다릅니다. 지금은 화면 시연을 위해 장착 요구 레벨로 아이템 레벨을 고정합니다.

기존 속성 설정

시작 상태에서 입력한 속성은 재료 사용량에 포함하지 않습니다. 모든 일반 장비 종류의 한글 속성 후보를 사용합니다. 확률은 아직 시연용입니다.

첫 오브를 사용하면 시작 아이템 설정이 잠깁니다.

목표 속성

목표 속성을 직접 편집합니다. 목표 설정은 오브를 소모하지 않습니다.
