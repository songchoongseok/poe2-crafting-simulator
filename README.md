### 데이터 정확도 경고

베이스와 한글 일반 속성 이름은 PoB2/GGPK 추출 자료, 에센스·오브의 한국어 속성과 조건은 PoE2DB를 기준으로 연결했습니다. **일반 옵션과 심연 공개 선택지의 실제 등장 가중치는 검증되지 않았습니다.** 기본 추첨은 균등이며, 촉진하는 찬미의 징조에서 적용하는 계열 편향도 임시값이므로 실제 성공률과 기대 소모량으로 해석하면 안 됩니다.

**추가 정확도 제한:** 기회의 오브로 생성되는 고유 아이템의 정확한 이름·속성 목록은 아직 없으며, 바알 오브의 타락 전용 부여 속성은 종류만 기록하고 실제 장비별 수치 풀을 제공하지 않습니다. 바알 오브의 결과 유형은 4가지 분기로 구현했지만 세부 속성 추첨은 미완성입니다. 에센스 확정 옵션의 접두/접미 및 속성 그룹은 한국어 설명을 기반으로 연결합니다. **품질 화폐의 아이템 레벨별 증가량은 임시 구간값**입니다. 룬·증강물 장착 및 교체, 실제 기폭제 품질 증가량, 정확한 고유 아이템 풀, 미검증 가중치, 징조 동시 활성화는 추가 검증이 필요합니다. 완벽한 게임 재현이라고 주장하지 않습니다.

## PoB2 베이스 선택 기능 (v0.3)

- 시작 아이템 설정에서 **장비 분류(방어구/무기/장신구) → 장비 종류 → 세부 유형 → 이름 검색 → 베이스** 순서로 선택합니다.
- PoB2 `src/Data/Bases/*.lua`에서 추출한 **1,474개** 일반 장비 베이스와 기존 사용자 지정 신발 1개를 제공합니다.
- PoB2 `dev` 브랜치의 고정 커밋 `bb52d6b368307457eb9c54bb13f1829993d390b1` 기준으로 추출했습니다.
- 게임 내 한글명이 검증된 *단검발 신발*만 한글 이름으로 표기하고, 나머지는 PoB2 영어 원문을 사용합니다. 잘못된 한글 명칭을 임의 생성하지 않습니다.
- 숨김(`hidden=true`) 및 비매품(`not_for_sale=true`) 베이스는 기본 목록에서 제외합니다.
- 아이템 요구 레벨, 기본 방어 능력치, 무기 물리 피해, 고정 속성 등 원본에서 파싱 가능한 정보를 표시합니다.
- **중요:** 현재 오브·속성 시연은 **회피/에너지 보호막 신발**에서만 동작합니다. 다른 베이스는 선택·정보 표시·세션 저장은 지원하지만 **장비별 실제 속성 풀이 준비되기 전까지 오브 사용을 차단**합니다.
- 주얼, 플라스크와 일부 특수/퀘스트 장비는 이번 일반 장비 목록에 포함하지 않습니다. 아이템 분류 목록을 추가해도 실제 제작 규칙과 가중치가 자동으로 생기는 것은 아닙니다.

데이터 구성: `data/pob2-armour.js`, `data/pob2-weapons-a.js`, `data/pob2-weapons-b.js`, `data/pob2-accessories.js`, 카테고리 필터는 `src/catalogue.js`, 화면 컨트롤은 `src/base-picker.js`입니다.

## 실제 개발 방향

1. PoB2 베이스·속성 데이터를 파싱하고 원본 ID 및 한국어 명칭을 매핑합니다.
2. 실제 등장 가중치를 확인하여 `미확인/추정/검증`으로 구분하고 재료별 최소 속성 레벨을 반영합니다.
3. 오브/징조/에센스/분열/심연 효과를 서로 다른 검증 규칙으로 구현합니다.
4. 정상/사용 불가/속성 그룹 중복/보호 및 제거/확률 검증 테스트를 통과시키고 기능을 공개합니다.
5. 수동 제작 → 자동 시뮬레이션 → 세로형 Workflow 내보내기 순서로 확장합니다.

**작업 원칙:** 주얼은 현재 범위에서 제외합니다. 초기 아이템은 복수 베이스와 원하는 희귀도·기존 속성으로 시작할 수 있어야 하며, 오브는 클릭 즉시 사용합니다. 오브/징조가 실제로 소모됐을 때만 누적 사용량이 증가합니다. 전 과정을 순서대로 로그로 남깁니다.
